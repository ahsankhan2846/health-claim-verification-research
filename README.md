# Health Claim Verification Research

Research materials for **Same Claim, Different Script: A Multi-Form Benchmark for Health Claim Verification in English, Urdu, and Roman Urdu**.

The `deliverables/` directory contains the benchmark, manuscript, audits, annotation materials, notebook, analysis code, and documented pending work. `ready_deliverables.zip` contains the same files for download.

Experiment status: genuine single-model raw results are present for Qwen 2.5 1.5B; translation/evidence review and few-shot execution remain pending and are explicitly documented; no experimental results are fabricated.

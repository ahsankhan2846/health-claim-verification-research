# Data dictionary

| Column | Meaning |
|---|---|
| `claim_id` | Stable claim identifier from HC_001 through HC_070. |
| `topic` | Health topic category. |
| `claim_type` | Claim rhetorical or evidential type. |
| `english` | English reference wording. |
| `urdu` | Urdu-script rendering. |
| `roman_urdu` | Roman Urdu rendering. |
| `gold_label` | Provisional Supported, Refuted, or Insufficient label. |
| `source_title` | Evidence source title. |
| `source_url` | Evidence source URL; pending live verification. |
| `source_note` | Brief source-to-label rationale. |
| `spelling_variants` | Roman Urdu variants where recorded. |
| `review_status` | Current human-review status. |
| `claim_type_normalized` | Heuristic claim-type grouping for analysis. |

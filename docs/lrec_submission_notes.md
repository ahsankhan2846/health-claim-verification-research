# LREC-style submission notes

## Prepared artifacts

- `manuscript/lrec_submission.tex`: anonymized review-mode source.
- `manuscript/lrec_template/lrec2026.sty`: downloaded LREC 2026 style file.
- `deliverables/lrec_submission_anonymized.pdf`: compiled review PDF.
- `manuscript/final_research_paper.md`: editable content source.
- `deliverables/final_research_paper.docx`: editable Word manuscript.

## Checks completed

- A4, two-column LREC style.
- Review-mode anonymization.
- Abstract within the official 150–200 word range.
- Limitations and ethics after the conclusion.
- Three content pages, below the eight-page submission maximum.
- References and data/code availability included.

## Before actual submission

The LREC 2026 submission window is closed. For a future LREC-COLING call,
re-check the official author kit, dates, anonymity rules, copyright terms, and
whether the style file has changed. Human translation/evidence validation,
source URL checks, and any additional experiments remain scientific—not
formatting—requirements and are not fabricated here.
